# 지금, 어디에 주차할까? 🅿️

서울시 공영주차장의 **혼잡도·요금·운영시간을 비교하고 길찾기까지 이어지는 지도형 대시보드**입니다.

> **지역의 혼잡도를 파악하고 → 실제 주차장을 비교하고 → 길찾기로 이동합니다.**

🔗 **[대시보드 바로 보기](https://hewa5318.github.io/parking-congestion-map/)**

## 프로젝트 소개

주차장을 찾을 때 필요한 정보는 한 가지가 아닙니다.

어느 지역이 붐비는지,  
개별 주차장은 얼마나 찼는지,  
요금은 얼마인지,  
언제까지 운영하는지를 함께 확인해야 실제 선택으로 이어집니다.
