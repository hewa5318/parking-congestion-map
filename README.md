# 지금, 어디에 주차할까? 🅿️

서울시 공영주차장의 혼잡도·요금·운영시간을 비교하고, 선택한 주차장의 길찾기로 이어지는 지도형 대시보드입니다.

**지역을 살펴보고 → 개별 주차장을 비교하고 → 이동할 곳을 정합니다.**

**[대시보드 바로 보기](https://hewa5318.github.io/parking-congestion-map/)**

> 현재 공개본은 2026년 10월 12일 수집 데이터를 담은 시연본입니다. 실시간 주차정보를 활용했지만, 접속할 때마다 최신 데이터를 불러오거나 자동 갱신하지는 않습니다.

## 왜 만들었나요?

주차장을 고를 때는 위치만으로 결정하기 어렵습니다. 가까운 곳에 자리가 있는지, 요금은 얼마인지, 이용하려는 시간에도 운영하는지를 함께 확인해야 합니다.

이 프로젝트에서는 주차정보를 보여 주는 데서 한 걸음 더 나아가, **정보를 비교한 뒤 실제로 이동할 곳을 정하는 과정**을 한 화면에 연결하고자 했습니다.

지역별 상황을 먼저 살펴보고, 지도에서 개별 주차장의 조건을 확인한 뒤, 외부 지도 서비스에서 길찾기를 이어가도록 구성했습니다.

## 어떻게 사용하나요?

1. **전체 상황을 확인합니다.** 상단 카드에서 주차장 수와 혼잡률, 여유·혼잡 주차장 수를 살펴봅니다.
2. **관심 지역을 선택합니다.** 자치구별 차트의 막대나 자치구 이름을 누르면 지도의 해당 지역으로 이동합니다.
3. **주차장을 비교합니다.** 지도 마커를 눌러 혼잡률, 기본·추가 요금, 일 최대 요금, 평일·주말 운영시간을 확인합니다.
4. **길찾기를 이어갑니다.** 팝업의 ‘카카오맵으로 길찾기’를 누르면 해당 주차장을 목적지로 연결합니다.

시연할 때는 ‘자치구 선택 → 주차장 팝업 확인 → 길찾기’ 순서로 살펴보면 화면의 흐름을 확인할 수 있습니다.

## 중요하게 본 설계 판단

### 지역 비교와 주차장 선택을 연결했습니다

자치구별 차트는 어느 지역을 살펴볼지 정하는 데 도움이 되지만, 실제로 주차할 장소까지 알려 주지는 않습니다. 차트와 지도를 따로 탐색해야 하는 수고를 줄이기 위해, 막대와 자치구 이름을 누르면 해당 지역의 주차장들을 볼 수 있도록 연결했습니다.

### 주차장의 규모를 반영해 지역 혼잡률을 보여 줍니다

지역 혼잡률은 해당 지역의 전체 주차면 대비 주차 차량 비율로 표시합니다. 규모가 다른 주차장을 같은 비중으로 평균 내기보다, 얼마나 많은 주차면이 사용되고 있는지 비교하려는 구성입니다.

다만 이 값은 **데이터에 포함된 주차장들의 집계**이며, 해당 자치구의 모든 주차 상황을 대표하지는 않습니다.

### 혼잡도와 이용 조건을 같은 팝업에 배치했습니다

자리가 남아 있어도 요금이나 운영시간이 맞지 않으면 선택하기 어렵습니다. 혼잡률 아래에 요금과 운영시간을 함께 배치해, 주차장을 고르는 데 필요한 조건을 한 번에 확인하도록 했습니다. 확인 후에는 같은 팝업에서 길찾기로 이동할 수 있습니다.

### 색상에 상태 이름과 수치를 함께 표시했습니다

색상만으로 판단하지 않도록 혼잡률과 ‘여유·보통·주의·혼잡’ 상태를 함께 보여 줍니다.

| 상태 | 혼잡률 구간 |
| --- | --- |
| 여유 | 35% 미만 |
| 보통 | 35% 이상 ~ 70% 미만 |
| 주의 | 70% 이상 ~ 90% 미만 |
| 혼잡 | 90% 이상 |

이 구간은 화면에서 비교하기 위한 프로젝트의 분류 기준입니다. 서울시의 공식 혼잡 등급을 뜻하지 않습니다.

## 데이터 연결 과정

| 데이터·서비스 | 연결한 정보 | 화면에서의 역할 |
| --- | --- | --- |
| 서울시 시영주차장 실시간 주차정보 | 주차면·주차 차량 정보, 요금, 운영시간 등 | 혼잡률과 이용 조건 표시 |
| Kakao Local API | 주소를 바탕으로 보완한 위치 좌표 | 주차장 위치를 지도에 표시 |
| 카카오맵 길찾기 링크 | 주차장 이름과 좌표 | 선택한 주차장을 목적지로 연결 |

주차정보를 지역별 차트와 개별 주차장 팝업으로 나누어 표현하고, 차트에서 선택한 자치구를 지도로 전달하도록 연결했습니다. 주소 정보는 좌표로 보완해 지도 마커와 길찾기에 활용했습니다.

현재 저장소에는 이 결과를 담은 HTML이 공개되어 있습니다. 원자료 수집·가공 코드와 전체 재생성 절차는 포함되어 있지 않습니다.

## 구현 결과

**지역별 비교에서 개별 장소의 확인과 이동까지 이어지는 시연본을 구현했습니다.**

- 상단 요약 카드와 자치구별 혼잡률 차트
- 차트 선택에 따른 지도 이동
- 주차장별 혼잡도·요금·운영시간 팝업
- 선택한 주차장의 카카오맵 길찾기 연결
- 작은 화면에서 카드와 패널 배치를 조정하는 반응형 구성

현재 화면에는 주차정보 제공 주차장 122곳, 지도 표시 117곳이 안내되어 있습니다. 두 수치는 구분해서 보아야 하며, 집계 대상과 지도 표시 대상의 차이를 화면에서 더 명확하게 설명할 필요가 있습니다.

이 결과는 탐색 흐름을 구현한 단계입니다. 실제 이용자의 주차장 탐색 시간이나 선택 정확도가 개선되었는지는 아직 검증하지 않았습니다.

## 한계와 다음 단계

### 최신 정보와 수집 시점의 정보를 구분해야 합니다

공개본의 데이터는 자동으로 갱신되지 않습니다. 다음 단계에서는 화면의 ‘실시간·현재’ 표현을 수집 기준시각과 맞추고, 주기적 갱신 여부와 데이터 지연 상태를 명확히 안내할 필요가 있습니다.

### 미확인 정보를 ‘여유’나 ‘무료’로 오해하지 않도록 해야 합니다

현재 화면에는 갱신시각이 없는 주차장이 혼잡률 0%로 표시되는 사례가 있습니다. 실제 주차 차량이 없는 것인지, 정보가 누락된 것인지 구분하는 처리가 필요합니다. 요금도 0원과 미제공 값을 구별해 안내하도록 보완할 계획입니다.

### 집계 범위와 이용 대상을 더 분명히 해야 합니다

주차정보 제공 대상, 차트 집계 대상, 지도 표시 대상의 일치 여부를 점검하고 차이가 생긴 이유를 안내해야 합니다. 관광버스 전용 주차장처럼 일반 승용차 이용과 조건이 다른 장소도 별도로 구분할 필요가 있습니다.

### 실제 선택에 도움이 되는지 확인해야 합니다

‘목적지 근처에서 이용 가능한 주차장 고르기’와 같은 과제로 사용성을 확인하고, 필요한 경우 차량 유형·운영 여부·요금 조건으로 후보를 좁히는 기능을 검토할 계획입니다.

## 기술 구성과 실행 방법

| 구성 | 사용 기술 |
| --- | --- |
| 대시보드 | HTML, CSS, JavaScript |
| 지역별 차트 | Plotly.js |
| 지도 | Folium 생성 지도, Leaflet, Esri 지도 타일 |
| 차트·지도 연결 | JavaScript `postMessage` |
| 공개 | GitHub Pages |

별도 설치 없이 위의 대시보드 링크에서 볼 수 있습니다. 로컬에서는 저장소를 내려받아 `index.html`을 브라우저로 열면 됩니다. 지도 타일과 외부 라이브러리를 불러오기 위한 인터넷 연결이 필요합니다.

저장소의 HTML은 수집된 데이터를 담은 결과물입니다. 최신 데이터로 다시 만들기 위한 수집 환경이나 API 인증키는 포함되어 있지 않습니다.
